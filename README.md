# 🤟 نظام التعرف على لغة الإشارة (Sign Language Digits Recognition)

**المشروع النهائي — مادة تمييز الأنماط (Pattern Recognition)**

نظام ذكي يقوم بالتعرف على **إشارات الأرقام (0-9)** بلغة الإشارة من صور اليد، مبني باستخدام شبكة عصبية التفافية (CNN) **من الصفر بدون استخدام Transfer Learning**.

---

## 📌 فكرة المشروع

مساعدة ذوي الاحتياجات السمعية من خلال بناء نظام يحول إشارات اليد إلى أرقام مفهومة، حيث يقوم النظام بـ:

1. استقبال صورة يد تُشير إلى رقم معين
2. معالجة الصورة وتمريرها عبر شبكة عصبية التفافية (CNN)
3. إظهار الرقم المتوقع مع نسبة الثقة

---

## 📊 الـ Dataset

**Sign Language Digits Dataset** — متوفرة مجاناً على GitHub:

- **الرابط:** https://github.com/ardamavi/sign-language-digits-dataset
- **عدد الصور:** 2062 صورة ملونة (RGB)
- **دقة الصور:** 64×64 بكسل
- **عدد الفئات:** 10 فئات (الأرقام من 0 إلى 9)
- **نوع البيانات:** صور ✅ (مطابق لمتطلبات المشروع)

## 🧠 بنية الشبكة العصبية (CNN من الصفر)

تم بناء الشبكة يدوياً بدون أي Transfer Learning كما تقتضي متطلبات المشروع:

| الطبقة | الوصف |
|--------|-------|
| Input | صورة 64×64×3 |
| Conv2D (32 فلتر) + BatchNorm + ReLU + MaxPool | استخراج الملامح الأساسية |
| Conv2D (64 فلتر) + BatchNorm + ReLU + MaxPool | ملامح متوسطة |
| Conv2D (128 فلتر) + BatchNorm + ReLU + MaxPool | ملامح معقدة |
| Conv2D (256 فلتر) + BatchNorm + ReLU + MaxPool | ملامح تفصيلية |
| Flatten + Dense (256) + Dropout (0.5) | التصنيف مع منع الـ Overfitting |
| Dense (10, Softmax) | الإخراج — احتمالية كل رقم |

**تقنيات مستخدمة:**
- Data Augmentation (قلب أفقي، تغيير الإضاءة والتباين)
- Batch Normalization لتسريع التعلم
- Dropout لتقليل الـ Overfitting
- Early Stopping + Reduce LR on Plateau
- Adam Optimizer

## 🚀 خطوات التشغيل

### المرحلة الأولى: التدريب (على Google Colab)

1. افتح [Google Colab](https://colab.research.google.com)
2. ارفع ملف `notebook/sign_language_training.ipynb`
3. شغّل الخلايا بالترتيب من الأعلى للأسفل ⚙️ ← Runtime = GPU (اختياري لتسريع التدريب)
4. في نهاية الـ Notebook سيتم تحميل ملف المودل `sign_language_model.keras` تلقائياً إلى جهازك

### المرحلة الثانية: تشغيل الواجهة (على جهازك)

```bash

# 2. ثبّت المكتبات المطلوبة
```
